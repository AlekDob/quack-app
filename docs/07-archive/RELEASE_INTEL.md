# 🦆 Quack v0.1.0 - Intel Edition

First release of Quack! Multi-agentic desktop app powered by Claude SDK.

## 📦 Download

### macOS:

• **Intel Mac (2017-2020):** [Download](link-to-dmg) `Quack_0.1.0_x64.dmg`

Compatible with: iMac, MacBook Pro, Mac Mini, MacBook Air (Intel processors)

## 📋 Installation

1. Download the DMG file
2. Open the file
3. Drag Quack to Applications
4. On first launch: System Settings > Privacy & Security > "Open Anyway"

## 💻 System Requirements

- macOS 10.13 (High Sierra) or later
- Intel x86_64 processor
- 4GB RAM minimum (8GB recommended)

---

🦆 Built with Tauri, React & TypeScript

**Note:** This is the Intel-optimized build (~50MB). For Apple Silicon Macs (M1/M2/M3), download the ARM64 version.
