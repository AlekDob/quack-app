## How to Move Tasks Here

When you start working on a task:

1. **Copy or move** the task file from its priority folder to here
2. **Update status** in the task file: `Status: 🔄 In Progress`
3. **Create git branch**: `git checkout -b optimization/task-name`
4. **Update dashboard**: Update `docs/08-optimizations/README.md`

## Rules

- **Maximum 1-2 tasks** in progress at a time (focus!)
- **Daily updates** for long-running tasks
- **Move to completed** as soon as done (don't let tasks linger)
- **Move back to priority** if blocked or deprioritized
