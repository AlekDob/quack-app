# Introduction to Quack

Welcome to **Quack** - your multi-agentic AI-powered development environment! 🦆

## What is Quack?

Quack is a **Tauri desktop application** that brings together the power of Claude AI, integrated terminals, file management, and version control into a single, unified interface.

Think of it as your **AI-first IDE companion** that helps you:

- Run terminal commands with intelligent context
- Manage files and navigate your projects
- Interact with Claude AI for code assistance
- Control Git operations visually
- Record voice notes and brainstorm ideas
- Access MCP servers for extended capabilities

## Why Quack?

### Unified AI Workspace

Instead of switching between your terminal, IDE, browser, and AI chat:
- **All in one place**: Terminal + File Explorer + AI + Git
- **Context-aware**: Quack understands your project structure
- **Persistent sessions**: Your terminals and conversations stay alive

### Built on Claude Agent SDK

Quack leverages the powerful **Claude Agent SDK** to provide:
- Subagent coordination
- Skill system for specialized tasks
- MCP (Model Context Protocol) integration
- Tool calling and command execution

### Multi-terminal Support

Run multiple terminals simultaneously:
- Each terminal maintains its own session
- Switch between terminals without losing context
- Color-coded tabs for easy identification

## Who is Quack For?

**Developers** who want to:
- Speed up their development workflow
- Leverage AI assistance without context switching
- Keep all project tools in one place

**Claude Code Users** who need:
- Better visualization of Agent interactions
- Integrated terminal management
- File explorer for quick navigation

**Teams** looking for:
- Consistent development environments
- Shareable agent configurations
- Streamlined AI-assisted workflows
