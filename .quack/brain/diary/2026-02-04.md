# 2026-02-04 — UI Refinements + Performance Optimization (GPU/CSS)

## Lavoro completato

### 1. Performance Optimization — Riduzione CPU del 30-40%
**Problema**: Quack Graphics and Media process consumava 33.7% CPU con 110+ backdrop-filter blur e 120+ animazioni infinite

**Root causes identificate**:
- Blur pesanti (20-24px) su backdrop-filter forzavano GPU compositing
- Multi-layer box-shadow (3-4 livelli) su elementi animati
- Nessun pausing delle animazioni quando window perde focus o panel è collapsed

**Soluzioni implementate**:
1. **CSS Variables centralizzate** — `--blur-light: 4px`, `--blur-medium: 8px`, `--blur-heavy: 12px` in `index.css`
2. **Riduzione blur** — da 20-24px → 8-12px su tutti i componenti (terminal-pane, sidebar, side-panel-accordion)
3. **Semplificazione box-shadow** — da 3-4 layer → 1 layer su elementi animati (stationPulse, verticalPulse, shimmer)
4. **GPU optimization** — aggiunto `will-change: transform, opacity` su animazioni critiche
5. **Window focus pausing** — nuovo hook `useWindowFocus()` che:
   - Aggiunge `.window-blurred` class su `.app-shell` quando window perde focus
   - Regole CSS pausano animazioni: `.app-shell.window-blurred .session-dot { animation-play-state: paused !important; }`
   - Effetto: animazioni si fermano quando app è in background (battery saving)
6. **Visibility-based pausing** — regole CSS per pausare animazioni in panel collapsed o elementi nascosti
7. **Accessibility** — supporto `@media (prefers-reduced-motion: reduce)` per rispettare preferenze utente

**File modificati**:
- `src/index.css` — CSS variables, pausing rules, prefers-reduced-motion
- `src/App.css` — blur optimization su terminal-pane
- `src/components/SidePanelAccordion.css` — blur optimization
- `src/components/AgentSessionItem.css` — semplificazione stationPulse box-shadow
- `src/components/AgentSessionList.css` — will-change su verticalPulse
- `src/components/ToolCallMinimal.css` — will-change su shimmer, ottimizzazione gradiente
- `src/hooks/useWindowFocus.ts` — nuovo hook
- `src/App.tsx` — integrazione hook

**Commit**: `5968950` — "perf: optimize animations and rendering with GPU acceleration and focus-aware pausing"

**Risultato atteso**: CPU reduction 30-40%, migliore battery life, stessa UX

## Pattern applicati
- **Performance-first CSS**: CSS variables per valori ripetuti, riduzione blur/shadow
- **GPU optimization**: will-change property per hinting browser
- **Battery saving**: animation pausing basato su window focus e visibility
- **Accessibility**: prefers-reduced-motion support
- **Custom hooks**: useWindowFocus per logica riutilizzabile

## Decisioni architetturali
- Preferito CSS puro per pausing invece di JS listeners su ogni animazione
- window focus check tramite class toggle invece di context/store (più performante)
- Blur reduction mantenendo glass effect riconoscibile (12px ancora sufficiente per UX)

## Note tecniche
- **Quack Graphics and Media**: processo WebKit per backdrop-filter e canvas rendering
- **Animation play state**: `paused !important` override necessario per animazioni infinite
- **will-change**: usato solo su animazioni attive, non su tutto (memory overhead)

## Sessione pomeridiana/serale — UX refinements post-performance

### 3. Session Persistence — Chat History Hydration
**Problema**: Sessions persi al restart app — solo metadata persistito, messages in useState

**Soluzione implementata** (~35 righe):
- Nuova funzione `hydrateSessionMessages()` in `App.tsx`
- Chiamata dopo `loadSessions()` nel bootstrap useEffect
- Per ogni session con `claudeSessionId`, chiama Rust command `resume_session`
- Converte `SessionHistoryMessage[]` → `ChatMessage[]` e popola `chatSessions` Map
- Silently skips sessions che non possono essere ripristinate

**File modificati**:
- `src/App.tsx` — funzione hydration + chiamata bootstrap (linee ~260-300, ~6178-6220)
- `src/types.ts` — import `SessionDetails` aggiunto

**Performance impact**: Minimo — solo al boot, I/O locale (millisecondi per session)

**Commit**: Incluso in commit generale UI refinements

### 4. User Message Truncation — iMessage Bubble Fix
**Problema**: User messages troppo lunghi occupavano tutta la larghezza (image-258)

**Soluzione implementata**:
- **JS truncation**: `truncateText()` ora applicato a TUTTI user messages (non solo ultimo), 20 words / 150 chars
- **CSS truncation**:
  - `max-width: 350px` su bubble
  - `-webkit-line-clamp: 2` per 2 righe max
  - `text-overflow: ellipsis`
- Espansione su click mantiene testo completo

**File modificati**:
- `src/components/ChatMessage.tsx` — logica truncation modificata (linea ~513-516)
- `src/components/ChatMessage.css` — max-width e line-clamp (linea ~44-61)

**UX improvement**: Messaggi user sempre compatti, leggibili, coerenti con stile iMessage

### 5. DiffViewer Compactification — Less Clutter
**Problema**: DiffViewer troppo alto e largo, scroll orizzontale, font grandi

**Soluzione implementata**:
- `max-height: 400px → 200px` (50% reduction)
- `font-size: 12px → 10px`, `line-height: 1.6 → 1.4`
- `overflow-x: auto → hidden` + `white-space: pre → pre-wrap` (word wrap)
- `margin-bottom: 4px` tra diff hunks per separazione visiva
- Line numbers e markers ridimensionati (40px → 32px width)

**File modificati**:
- `src/components/DiffViewer.css` — tutti gli adjustment size/spacing

**UX improvement**: Diff leggibili ma non invadenti, meno scroll necessario

### 6. Session Ordering by Recency
**Request**: Ordinare sessions per `updatedAt` — most recent first

**Implementazione**:
- Aggiunto `.sort((a, b) => (b.updatedAt || 0) - (a.updatedAt || 0))` dopo filter in `AgentSessionList.tsx`
- Sessions ora ordinate dinamicamente — quella che risponde per ultima va in cima

**File modificati**:
- `src/components/AgentSessionList.tsx` — sorting logic

### 7. Time-Based Activity Coloring
**Request**: Indicatori temporali colorati — green (<5min), yellow (5-30min), grey (>30min)

**Implementazione**:
- Nuova funzione `getTimeColor(timestamp)` in `AgentSessionItem.tsx`
- Calcola colore basato su millisecondi da `updatedAt`
- Applicato a:
  - **Session timestamp text** — mostra "2m ago" in verde, "15m ago" in giallo, etc.
  - **Activity indicator dot** — pallino circolare dentro `div.session-item`
- Metro station dot NON usa questo sistema — mantiene `agentColor`

**Colori**:
- `#22c55e` (Tailwind green-500) — < 5 minuti
- `#f59e0b` (Tailwind amber-500) — 5-30 minuti
- `rgba(255, 255, 255, 0.45)` — > 30 minuti (grigio default)

**File modificati**:
