# 2026-02-09 - Agent Bundle Export Fix + Success Notifications

## Session Summary

Fixed critical bug in agent bundle export system and added success notifications for better UX feedback.

## Problem 1: Agent Bundle Export Permission Error

**Reported by user**: Export button fails with `fs.write_file not allowed` permission error.

**Root cause**: `useBundleOperations.ts` was using `writeFile()` from `@tauri-apps/plugin-fs`, which only has read permissions in `capabilities/default.json`. Cannot write to user-selected paths outside app directory.

**Solution**: Created custom Rust commands that bypass plugin-fs restrictions:
- Added `write_binary_file(path, data)` in `src-tauri/src/fs.rs`
- Added `read_binary_file(path)` for symmetry (also needed for avatar + import)
- Registered both in `lib.rs`
- Updated `useBundleOperations.ts` to use `invoke('write_binary_file')` instead of plugin-fs

**Why it works**: Rust `std::fs` has no Tauri capability restrictions, runs with user permissions.

## Problem 2: No Export Success Feedback

**User request**: "basta solo mettere una notifica di download confermato"

**Solution**: Added auto-dismissing success notification:
- Extended `useBundleOperations` state with `success: string | null`
- Set success message after export/import, auto-clear after 3s with setTimeout
- Rendered `<div className="bundle-success-compact">` in `AgentPersonalityCard`
- CSS animation: fade-in 450ms → visible 1.8s → fade-out 750ms
- Cyan color `#00D9FF` (brand color), matches error position

## Technical Details

### Binary File I/O Pattern

**Challenge**: Tauri plugin-fs is sandboxed, can't write to arbitrary user paths.

**Solution**: Use Rust stdlib directly via custom commands.

```rust
// Rust side (src-tauri/src/fs.rs)
#[tauri::command]
pub fn write_binary_file(path: String, data: Vec<u8>) -> Result<(), String> {
    if let Some(parent) = std::path::Path::new(&path).parent() {
        std::fs::create_dir_all(parent).map_err(|e| format!("Failed to create parent dirs: {}", e))?;
    }
    std::fs::write(&path, &data).map_err(|e| format!("Failed to write binary file: {}", e))
}

// TypeScript side (useBundleOperations.ts)
await invoke('write_binary_file', {
  path: savePath,
  data: Array.from(zipData)  // Uint8Array → number[]
});
```

**Key insight**: `Vec<u8>` in Rust maps to `number[]` in TypeScript, not `Uint8Array`. Must convert with `Array.from()`.

### Success Notification Pattern

**Auto-dismiss timing**:
- Set success state immediately after operation
- Schedule clear after 3000ms with `setTimeout`
- CSS animation handles visual timing (fade-in/out)

**Why not global toast system?**
- Only one use case currently
- Compact sidebar UI — limited space
- Simple solution (23 lines) vs complex system (hundreds of lines)
