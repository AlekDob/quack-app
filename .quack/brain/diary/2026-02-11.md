# 2026-02-11

- Fixed navigation bugs: session view wasn't clearing when marking done or creating new agent. Added callback chain to reset `activeSessionId` and `activeTaskId`. See bugs/fix-navigation-after-session-done-and-new-agent.md
- Fixed "Quack quack..." notification badge showing on all agents at startup (two root causes): 1) `lastReadTimestamps` was empty Map at boot, 2) badge was counting `done` sessions whose messages were still in memory but hidden in sidebar. Fix: boot timestamp init + filter `activeSessions` excluding `done` status in both SortableAgent and worktree sections. See bugs/fix-notification-badge-on-app-startup.md
- Implemented "Teammate Stream Drill-Down" feature: clicking TeammateWidget opens dedicated tab with real-time activity stream. Rust backend watches JSONL session logs via notify crate (teammate_watcher.rs), frontend renders events in TeammateStreamTab.tsx. 2 new files + 8 modified. See patterns/teammate-stream-drilldown.md and decisions/decision-teammate-stream-file-watcher.md
- Fixed auto-scroll during streaming: users couldn't scroll up to review previous messages because auto-scroll forced them back to bottom. Added `userHasScrolledUpRef` to MessageList.tsx that tracks user scroll-up during streaming and disables auto-scroll until user returns to bottom or streaming ends. Discord user feedback (meaning, 2026-02-08). See bugs/fix-chat-auto-scroll-during-streaming.md
