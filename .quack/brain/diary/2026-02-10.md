### 2. Critical Bug Fix — Windows Install Path Separators
**Report utente**: Utenti Windows non riescono a installare nulla dal Quack Store — "Failed to install" su skills, agents, commands, rules.

**Root cause**: `useMarketplace.ts` costruiva tutti i path con string concatenation + forward slash `/` hardcoded:
```typescript
// BROKEN
let home = await homeDir();  // "C:\Users\Username" su Windows
if (!home.endsWith('/')) home += '/';
const targetPath = `${home}.claude/agents/${agentFile}`;
// Result: "C:\Users\Username/.claude/agents/file.md" ❌ Mixed separators
```

Su Windows `homeDir()` ritorna `C:\Users\Username` con backslash, ma il codice aggiungeva `/`, creando path misti che le operazioni filesystem rifiutano.

**Soluzione**: Sostituito **tutte** le concatenazioni stringa con `join()` di `@tauri-apps/api/path`:
```typescript
// FIXED
import { homeDir, join } from '@tauri-apps/api/path';
const home = await homeDir();
const targetDir = await join(home, '.claude', 'agents');
const targetPath = await join(targetDir, agentFile);
// macOS: "/Users/alek/.claude/agents/file.md" ✅
// Windows: "C:\Users\alek\.claude\agents\file.md" ✅
```

**Scope del fix**:
- `checkInstalledResources()` — 4 path (check installed status)
- `installResource()` — basePath + 8 path (4 categorie × dir+file)
- `uninstallResource()` — 5 path (remove operations)
- `installAgentBundle()` — 4 path (bundled skills + rules)
- **Totale: 21 path constructions fixed**

**File modificati**:
- `src/hooks/useMarketplace.ts` — import `join`, update 4 funzioni

**Testing**: TypeScript compila senza errori, backward compatible con macOS.

### 3. Critical Bug Fix — Agent Bundle Install Routing (Mac + Windows)
**Report utente**: Utenti Mac (e Windows) non riescono a installare agent bundles dalla sezione Featured — "Failed to install" su Agent Jack, Agent Fredric, Agent Roberta, etc.

**Root cause**: `QuackStoreDrawer.tsx` chiamava `installResource()` per TUTTI i resource types, includendo agent bundles. Ma `installResource()` gestisce solo resources individuali con `_skillPath`, `_commandPath`, `_agentPath`, `_rulePath`.

Agent bundles hanno `_agentTemplate` invece, quindi cadevano nel ramo `else`:
```typescript
// In installResource() linea 459
} else {
  throw new Error('Unknown resource type');  // ❌ Agent bundles qui
}
```

**Differenza chiave**:
| Resource | Category | Funzione | Cosa fa |
|----------|----------|----------|---------|
| Skill | `skills` | `installResource` | Download 1 SKILL.md |
| Agent/Droid | `agents/droids` | `installResource` | Download 1 .md file |
| **Agent Bundle** | `agent-bundles` | `installAgentBundle` | Download multiple skills+rules + crea UnifiedAgent |

**Soluzione**: Aggiunto routing logic in `QuackStoreDrawer.handleInstall()`:
```typescript
if (resource.category === 'agent-bundles') {
  if (!projectPath) {
    toast.error('Open a project first to install agent bundles', { id: toastId });
    return false;
  }
  await installAgentBundle(resource, projectPath, projectName);
  toast.success(`${resource.name} installed`, { id: toastId, duration: 4000 });
  onRefresh?.();
  return true;
}
// Regular resources
const success = await installResource(resource, scope, projectPath);
```

**UX improvement**:
- **Before**: Click "Get" → "Failed to install" (errore criptico)
- **After**: Click "Get" con progetto aperto → Agent installato con skills/rules
- **After**: Click "Get" senza progetto → "Open a project first to install agent bundles" (messaggio chiaro)

**File modificati**:
- `src/components/QuackStoreDrawer.tsx` — import `installAgentBundle`, update `handleInstall()` logic

**Testing**: TypeScript compila senza errori, featured bundles ora installabili.

## Pattern applicati
- **Cross-platform path handling**: Sempre usare `join()` da `@tauri-apps/api/path`, mai string concat con `/` o `\`
- **Type-based routing**: Agent bundles richiedono workflow diverso da resources individuali
- **Error messaging**: Messaggi chiari e actionable invece di generici "Failed to X"

## Decisioni architetturali
- Agent bundles richiedono `projectPath` e `projectName` obbligatori (creano UnifiedAgent tied to project)
- Install routing gestito in UI layer (`QuackStoreDrawer`) invece di dentro hook (migliore separazione concerns)

## Impact
- **Windows compatibility**: Unlock completamente Quack Store per utenti Windows (bug blocker)
- **Mac agent bundles**: Featured bundles (starter agents) ora funzionanti per tutti gli utenti
- **Better UX**: Messaggi di errore chiari invece di generic failures

## Note tecniche
- `join()` normalizza automaticamente path separators per ogni OS
- Agent bundles sono gli unici resource type con `_agentTemplate` invece di `_skillPath`/etc.
- Featured resources (`r.featured === true`) vengono mostrati in hero banner + featured grid
