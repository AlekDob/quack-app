# Quack Brain Tag System

Sistema di tagging per organizzare le note nel vault Obsidian

REGOLA FONDAMENTALE: ogni nota ha UN SOLO TAG

#component - Componenti UI (React, Vue, SwiftUI)

#function - Funzioni e metodi riutilizzabili

#api - Endpoint API, MCP tools, webhooks

#pattern - Pattern architetturali e best practices

#bug - Bug fix e soluzioni a problemi

#decision - Architectural Decision Records (ADR)

#task - Task completati (documentazione lavoro)

#config - Configurazioni e setup

#idea - Idee da esplorare

#todo - Task in corso da completare

#human - Persone e contatti (SEMPRE globale)

#note - Appunti generici

#glossary - Traduzione termini umani → tecnici

#diary - Note giornaliere (SEMPRE in diary/)

#project - File principale di un progetto

Tag determina la cartella: #component → components/, #function → functions/, etc.
