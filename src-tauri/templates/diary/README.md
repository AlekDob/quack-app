# 📔 Project Diary System

Welcome to the **{{PROJECT_NAME}}** project diary! Quack quack! This system helps track daily progress, completed work, and project status.

## 🦆 How It Works

The diary system automatically creates daily entries to document work completion and project progress. Each day gets its own markdown file with a structured format.

### Daily Entry Structure

**Daily Work Logs** (`YYYY-MM-DD.md`):
- **Date and Project Info**
- **Completed Work** - What was accomplished today
- **Current Status** - Overall project health
- **Next Steps** - What's planned for tomorrow
- **Blockers** - Any issues or impediments
- **Team Notes** - Communication from Jack and the specialists

**Prompt Engineering Files** (`YYYY-MM-DD-prompts.md`):
- **Structured Prompts** - Carmelo's improved prompts from vague human requests
- **Context Documentation** - All necessary specifications and requirements
- **Question Lists** - Clarifications needed for incomplete requests
- **Prompt Evolution** - How requests were improved and structured

### Usage Guidelines

**Daily Work Logs:**
1. **Automatic Creation**: Mike (the Project Manager) creates daily entries when work is completed
2. **Progress Tracking**: Each entry builds on the previous day's work
3. **Team Coordination**: All agents can add notes to the daily log
4. **Status Updates**: Regular project health checks

**Prompt Engineering Files:**
1. **Carmelo's Domain**: Carmelo creates and maintains prompt engineering files
2. **Lazy Human Fixes**: When {{USER_NAME}} gives vague requests, Carmelo structures them
3. **Context Preservation**: All prompt improvements documented for future reference
