# Quack - Additional Details

## ✨ Key Features

### Multi-Terminal Emulator
- **Intelligent PTY Management**: Native terminal emulation with smart state detection (busy/idle)
- **Terminal Groups**: Organize your terminals into logical groups for better workflow
- **Custom Colors & Themes**: Personalize each terminal with accent colors and backgrounds
- **Smart Auto-Scroll**: Intelligent scroll management that doesn't interrupt your reading
- **Saved Commands**: Store and reuse your most frequent commands

### AI Assistant Powered by Claude Agent SDK
- **Real-time Streaming**: Messages stream in real-time with smooth rendering
- **Tool Usage Display**: Visual widgets show AI actions (Read, Write, Edit, Bash, Grep, Glob)
- **Session Persistence**: Resume your AI sessions anytime
- **Permission Control**: Three modes (plan/act/bypass) for different trust levels
- **Working Directory Binding**: AI operates in context of your active terminal
- **Cost Tracking**: Real-time cost tracking with USD amounts and token usage

### Git Integration
- **Visual Status Panel**: See your repository status at a glance
- **Side-by-Side Diff Viewer**: Compare changes with beautiful syntax highlighting
- **Interactive Staging**: Stage and unstage files with a single click
- **Commit UI**: Write commits with validation and author info
- **Timeline View**: Browse your commit history with ease

### File Explorer
- **Real-time Synchronization**: Always in sync with your active terminal's directory
- **File Preview**: View file contents with Monaco Editor (up to 5MB)
- **Context Menus**: Quick access to common file operations
- **Navigation History**: Go back and forward through your browsing history

### Developer Experience
- **Desktop Notifications**: Get notified when background processes complete
- **Audio Feedback**: Delightful "quack" sounds for terminal state changes 🦆
- **Preview System**: Auto-detect and preview running dev servers
- **HTTP Hooks**: Integrate with external tools like Claude Code
- **Performance Monitoring**: Built-in performance tracking and optimization
