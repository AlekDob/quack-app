PRODUCT UPDATE

Quack 0.9 is here.
Our biggest update yet.

Hi,

We've been shipping fast. Two major releases in one email because we were too busy building to write the first one. Here's everything new in Quack 0.8 and 0.9.

Integrated Code Editor

Full CodeMirror editor with multi-tab support, 23 languages, outline navigation, markdown and mermaid preview. Diff viewer with unified, split, and fullscreen modes. No need to leave Quack.

VS Code-style Split View

Drag any tab into a split pane to work side-by-side. Chat on the left, code on the right. Drag files, sessions, and features directly from the sidebar into split zones.

Whiteboard + Features

A visual canvas to map your project architecture. Features are a Quack-exclusive concept: logical building blocks you create with a single command, that become nodes on the Whiteboard, items on the Kanban, and living specs for your agents.

1M Token Context Window

Claude Opus 4.6 with 1M context window is now supported. Give your agents massive context for complex codebases. Combined with 120x prompt cache optimization, your tokens go further than ever.

Ask Mode + Plan Delegation

New Ask permission mode: see exactly what each tool will do before allowing it, with "Allow Always" per tool. Delegate approved plans to other agents with @mention routing.

Changes Panel

Codex-style diff panel in the sidebar. See every file modified during a session with inline diffs, syntax highlighting, and one-click IDE open. A glowing badge tells you when changes are active.

Premium UI + Customization

Complete visual redesign with liquid glass panels and cleaner hierarchy. 10 accent color presets plus custom picker. Font family and size customization. Collapsible right sidebar for maximum workspace.

Brain Hooks + HTML Visualizer

The Second Brain now surfaces gotchas and patterns automatically before you read or write files. Plus: inline HTML rendering lets agents produce charts, reports, and interactive widgets directly in chat.

Plus: improved subagent rendering, better project group management, enhanced chat input, markdown/mermaid reader, and dozens of bug fixes across macOS and Windows.
