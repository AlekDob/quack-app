# Demo File

Welcome to Quack - your multi-agentic desktop companion.

## What is Quack?

Quack is a powerful Tauri desktop application that combines:

- **Multi-terminal PTY** - Run multiple terminal sessions
- **File Explorer** - Browse and manage your files
- **Git Integration** - Version control at your fingertips
- **AI Assistant** - Powered by Claude Agent SDK
- **Voice Recording** - Capture ideas on the fly
- **Plugin System** - Extend functionality with MCP servers

## Quick Start

1. Open a terminal tab
2. Navigate to your project
3. Let AI agents assist you

## Philosophy

> "Human = architect, AI = builder"

Quack embraces the AI-first development approach where you focus on vision and direction while AI handles implementation details.
