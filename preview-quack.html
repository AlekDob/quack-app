Built to stay out of your way

Premium minimal, dark-first, and fast. No bloat, no lock-in.

Agent state at a glance

Every agent shows a live dot — working, waiting for input, or done. Jump straight to whichever one needs you.

Bring your own model

Claude Code, Cursor CLI, Anthropic, OpenAI, Ollama. Your keys, your models — swap providers per chat.

Native, not Electron-heavy

Tauri 2 + Rust. Native macOS window, ~30 MB on disk, instant cold start. No background telemetry.

Full editor inside

Monaco editor, integrated terminals, git diffs, Mermaid + HTML preview. Everything a real project needs.

Sessions that resume

Per-provider session ids, atomic transcript persistence. Close Quack, reopen, pick up exactly where you left off.

Multi-project hub

Color-coded workspaces and a cross-project agent hub. See what's running everywhere, from one rail.
