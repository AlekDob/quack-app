# v0.1.3

## 🦆 Quack v0.1.3 - Git Branch Selection Fix

### ✨ What's New

#### 🎨 UI/UX Improvements
- ✅ **Compact File Explorer** - Significantly reduced vertical spacing throughout the File Explorer for better screen real estate usage
  - Smaller font sizes (title: 0.7rem → 0.65rem, file names: 0.68rem → 0.65rem)
  - Reduced padding on rows (0.15rem → 0.1rem) and headers (0.7rem → 0.5rem)
  - Tighter gap between elements (0.35rem → 0.3rem)
  - Smaller Reveal in Finder button (16px → 13px)
- ✅ **Compact Plan Mode** - Made the plan widget more space-efficient
  - Reduced padding throughout (header: 14px 16px → 10px 12px)
  - Smaller font sizes (title: 14px → 13px, content: 13px base)
  - Tighter line height (1.6 → 1.5) and reduced margins
  - Smaller badges and icons for cleaner appearance
- ✅ **File Viewer Scrolling Fix** - Resolved double scrollbar issue in the file viewer
  - Fixed overflow handling to prevent duplicate scrollbars
  - Editor now properly fills all vertical space
  - Horizontal scrollbar no longer hides the last line
  - Single smooth scrolling experience
- ✅ **VS Code Dark+ Code Editor Theme** - Professional syntax highlighting with pure black background
  - Pure black background (#000000) for better contrast and eye comfort
  - Custom Lezer-based syntax highlighting using VS Code Dark+ color palette
  - Muted, professional colors (no bright red/blue)
  - Strings: Warm orange (#ce9178)
  - Keywords: Soft purple (#c586c0)
  - Variables/Properties: Light blue (#9cdcfe)
  - Comments: Olive green (#6a9955)
  - Numbers: Sage green (#b5cea8)
  - Functions: Yellow-gray (#dcdcaa)
  - Types/Classes: Teal (#4ec9b0)
  - Desaturated palette that's easy on the eyes for long coding sessions

#### 📝 New Features
- ✅ **Files Modified Summary Bar** - Fixed summary bar above chat input tracking file modifications from the last AI response
  - **Fixed position** above the chat input area (not repeated per message)
  - **Per-chat tracking** - each agent/terminal has its own independent summary
  - **Automatic updates** when new AI responses arrive
  - **Auto-clears** when you send a new message
  - **Expandable/collapsible** design to save screen space
  - Shows **file count** and **total number of changes**
  - Click on any file to **open it directly** in a tab
  - **"Open All Files"** button for quick access to all modified files
  - Tracks only modifications from the **current AI response** (resets on new user input)
  - Compact and minimal UI matching Quack's design system
  - Green theme to indicate file modifications
  - Automatic tracking of Edit and Write tool calls
  - Beautiful dark mode support

#### 🔧 Critical Bug Fixes
- ✅ **Git branch selection fix** - Fixed critical bug where creating an agent with "Use existing" branch option would fail with "branch named 'main' already exists" error
- ✅ **Branch detection improvements** - Agent creation now properly detects and uses the current repository branch
- ✅ **Better error handling** - Added fallback logic to skip invalid Git operations when branch doesn't exist
- ✅ **Agent Chat Duplicate Messages Fix** - Resolved rendering issue causing duplicate messages in agent chat UI
  - Implemented event deduplication system in `useClaudeChat.ts` using unique event ID tracking
  - Enhanced React key generation in `ChatMessage.tsx` to use stable IDs from event data
  - Added debug warning logs for duplicate event detection
  - Improved rendering performance by preventing unnecessary re-renders
  - System initialization messages and agent responses no longer appear duplicated

### 📦 Downloads

**macOS Universal (Intel + Apple Silicon):**
- Single DMG works on all Mac architectures
- Optimized performance on both Intel and Apple Silicon

### 🔧 Installation

1. Download `Quack_0.1.3_universal.dmg`
2. Open the downloaded file
3. Drag Quack to your Applications folder
4. Open Quack from Applications
5. On first launch, go to System Settings > Privacy & Security and click "Open Anyway"
