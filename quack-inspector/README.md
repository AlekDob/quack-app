# 🦆 Quack Inspector

> AI-powered component inspector for React, Vue, and Angular

Quack Inspector is a Chrome extension that helps developers quickly identify frontend components and generate AI-ready documentation. Perfect for giving precise instructions to AI coding assistants like Claude!

## Features

- 🔍 **Visual Inspector** - Click-to-inspect any element on the page
- 🎯 **Framework Detection** - Automatically detects React, Vue, Angular, or generic HTML
- 📋 **AI-Ready Output** - Generates markdown formatted for AI consumption
- 🎨 **Visual Highlighting** - Hover to see component boundaries
- 📚 **Inspection History** - Keeps track of recently inspected components
- ⌨️ **Keyboard Shortcuts** - Quick access with hotkeys
- 🎨 **DevTools Panel** - Integrated Chrome DevTools panel

## Installation

### From Source (Development)

1. Clone or download this repository
2. Open Chrome and navigate to `chrome://extensions/`
3. Enable "Developer mode" (toggle in top right)
4. Click "Load unpacked"
5. Select the `quack-inspector` folder

### From Chrome Web Store (Coming Soon)

Once published, you'll be able to install directly from the Chrome Web Store.

## Usage

### Method 1: Extension Popup

1. Click the Quack Inspector icon in your Chrome toolbar
2. Click "Start Inspecting"
3. Hover over elements on the page to preview
4. Click any element to inspect it
5. Component info is automatically copied to clipboard!

### Method 2: Keyboard Shortcuts

- **⌘/Ctrl + Shift + Q** - Toggle inspector mode
- **⌘/Ctrl + Shift + C** - Copy last inspected component

### Method 3: DevTools Panel

1. Open Chrome DevTools (F12 or ⌘+Option+I)
2. Click the "Quack 🦆" tab
3. Use the inspector from within DevTools

## What Gets Detected?

### React Components

```markdown
## 🦆 Component Inspector

**Framework**: React

**Component**: `TerminalDrawer`

**File**: `src/components/TerminalDrawer.tsx`

**Parent Chain**: App > TerminalWindowsPanel > TerminalDrawer

**Props**:
```json
{
  "isOpen": true,
  "terminalId": "abc-123",
  "onClose": "[Function: onClose]"
}
```

**DOM Path**:
```css
div.terminal-drawer.open > div.terminal-drawer-panel
```

---
*Generated by Quack Inspector 🦆*
```

### Vue Components

Detects Vue 2 and Vue 3 components with:
- Component name
- Props
- Data properties
- Computed properties
- Parent chain
- Source file

### Angular Components

Detects Angular components with:
- Component name
- Properties
- Injector info
- DOM structure

### Generic HTML

Falls back to generic DOM inspection for non-framework elements:
- Tag name
- ID and classes
- Attributes
- Computed styles
- DOM path

3. Update `inspector/formatter.js` with formatting logic
4. Test thoroughly with sample apps

## Troublesho## Troubleshooting

### Inspector doesn't activate

- Make sure you've refreshed the page after installing the extension
- Check that the page isn't a chrome:// or other restricted URL
- Look for errors in the console (F12 → Console)

### Framework not detected

- Some bundlers obfuscate framework internals
- Try enabling source maps in your build
- The extension will fall back to generic HTML inspection

### Copy to clipboard doesn't work

- Make sure the extension has clipboard permissions
- Some sites may block clipboard access
- Try using the keyboard shortcut instead
