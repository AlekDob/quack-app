#### Part 2: Activity Bar Integration

**Three Possible Approaches** (Alek needs to choose):

**Option A: Add Chat Item to TerminalActivityBar**

**Option B: Create Separate ChatActivityBar Component**
- Pros: Clean separation of concerns
- Cons: Two separate components to maintain
- Implementation:
  - Create `/src/components/ChatActivityBar.tsx`
  - Same structure as TerminalActivityBar
  - Place it in sidebar next to terminal list
  - Props: `chatStatus: 'idle' | 'busy'`

**Option C: Global Status Indicator (Minimal)**
- Pros: Least intrusive, simple implementation
- Cons: Less visible, harder to track multiple chats
- Implementation:
  - Add small badge/dot in top-right of chat panel
  - Show ⚡ when streaming, ✓ when idle
  - No sidebar integration

**Recommended**: Option B (Separate Component) for clean architecture

## 🦆 Carmelo's Commentary

Alek's request is actually pretty clear once you parse the Italian - he wants parity between terminal notifications and chat notifications. The tricky part is the "coordinare con TerminalActivityBar" bit - it's vague whether he wants to extend the existing component, create a new one, or just add a simple indicator.

**My Recommendation**: Create a separate `ChatActivityBar` component that mirrors the terminal one. Why?
1. Clean separation of concerns (chat ≠ terminal)
2. Easier to maintain and extend
3. Future-proof for multiple chats
4. Doesn't pollute TerminalActivityBar with chat logic

The notification part is straightforward - just copy the terminal pattern and wire it to `useClaudeChat`'s state changes. The only gotcha is ensuring we don't spam notifications if the user is rapidly sending messages.
