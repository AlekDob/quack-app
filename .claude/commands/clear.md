# Clear Conversation

Clear the current conversation history and start a completely fresh session.

## What This Does

- Clears all previous messages in the current chat
- Starts a new Claude session with fresh context
- Preserves your agent configuration and settings
- Resets the conversation to a clean slate

## When to Use

Use `/clear` when you want to:
- Start a completely new topic without previous context
- Reset after a long conversation to save tokens
- Begin a new task unrelated to previous work
- Clear confusion from previous context

## Effect

After running `/clear`:
- Message history is cleared
- New session ID is generated
- Token count resets to 0
- All previous context is discarded

**Note**: This cannot be undone. Make sure you've committed any important work before clearing!
