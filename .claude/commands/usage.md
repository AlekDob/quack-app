# Session Usage Statistics

Display comprehensive usage statistics including tokens consumed, costs incurred, and session metrics for the current conversation.

## What You'll See

### 📊 Token Usage
- **Input tokens**: Tokens sent to Claude (your prompts + context)
- **Output tokens**: Tokens generated by Claude (responses)
- **Cache tokens**: Tokens read from cache (reduced cost)
- **Total tokens**: Complete session usage

### 💰 Cost Breakdown
- **Current session cost**: Cost for this conversation
- **Cost per message**: Average cost per interaction
- **Estimated cost**: Projected cost if conversation continues
- **Cost by model**: Breakdown if using multiple models

### ⏱️ Session Metrics
- **Session duration**: How long this conversation has been active
- **Message count**: Total messages exchanged
- **Average response time**: Claude's response speed
- **Session ID**: Current session identifier

### 📈 Context Status
- **Context window**: Percentage of available context used
- **Messages stored**: Number of messages in history
- **Compaction status**: Whether history has been compressed
- **Tokens remaining**: Available context space

## Cost Reference (Sonnet 4.5)

- **Input tokens**: $3.00 per 1M tokens
- **Output tokens**: $15.00 per 1M tokens
- **Cache reads**: $0.30 per 1M tokens
- **Cache writes**: $3.75 per 1M tokens

## When to Use

Use `/usage` to:
- **Monitor costs** during development
- **Check context usage** before continuing work
- **Track session efficiency** and response times
- **Decide if compaction needed** to reduce token usage
- **Understand model performance** and optimization

## Integration with Other Commands

- Use `/compact` if token usage is high
- Use `/clear` if you want to reset and start fresh
- Check usage before long coding sessions
- Monitor costs during expensive operations (like large file reads)
