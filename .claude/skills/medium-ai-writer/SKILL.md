# Medium AI Writer Skill

Specialized skill for investigating AI development trends and optimizing technical content for Medium's platform.

## Capabilities

- **Trend Analysis**: Validate topic viability through search volume and competitive analysis
- **SEO Optimization**: Generate Medium-specific SEO titles (40-50 chars) and descriptions (140-156 chars)
- **Topic Discovery**: Identify high-performing content angles in AI/enterprise space
- **Keyword Research**: Find primary and long-tail keywords for technical content
- **Content Structure**: Optimize article hierarchy and readability for engagement

## How to Use

1. **Quick Assessment**: Start with a topic idea for rapid trend validation
2. **Deep Research**: Request detailed analysis for competitive landscape and keywords
3. **SEO Optimization**: Submit draft for Medium-specific SEO enhancements
4. **Topic Exploration**: Discover trending topics in your domain

## Input Format

Provide one of:
- Topic idea or keyword for trend research
- Article draft for SEO optimization
- Industry/domain for topic discovery
- Specific question about AI content trends

## Output Format

Returns structured analysis with:
- **Stage 1**: Quick go/no-go recommendation with trend status
- **Stage 2**: Detailed competitive analysis and keyword strategy
- **Stage 3**: Complete SEO optimization with Medium specifications

## Example Usage

```
User: "I want to write about Agent Skills in enterprise"
Assistant: Runs research_trends.py → Returns trend analysis
Result: Trending topic, low competition, high search volume

User: "Optimize my draft about Claude Code"
Assistant: Runs optimize_seo.py → Returns SEO improvements
Result: SEO title, description, tags, structure recommendations

User: "What AI topics are hot for enterprise PMs?"

Result: Top 5 trending and evergreen topics with angles
```

## Scripts

- **research_trends.py**: Analyzes topic trends, search volume, and competition
- **optimize_seo.py**: Generates Medium-compliant SEO elements with viral pattern formulas
- **analyze_topics.py**: Discovers trending and evergreen topics by domain

## Success Patterns

The skill uses proven patterns from top-performing Medium articles (689 and 624 claps):

- **Contrarian Stance**: "Why I DON'T Use X" - challenges mainstream assumptions
- **Scale Indicators**: "How We Built X at Scale" - demonstrates authority with specifics
- **Personal Experience**: "I Spent 6 Months..." - authentic storytelling with lessons

📚 **Reference**: See `success_patterns.md` for complete blueprints, formulas, and pre-publish checklist

### Title Formula Examples
- Contrarian: "Cretaceous {topic} — Why I Don't Follow the Mainstream"
- Scale: "How We Built {topic}: Part 1 — Real-World Implementation at Scale"
- Personal: "I Spent 6 Months Building {topic}. Here's What Actually Works"

### Key Metrics
- **Optimal Reading Time**: 6-7 minutes
- **Structure**: 5-7 H2 section headers
- **Engagement**: Personal story + specific numbers + 2-3 visuals
- **Viral Coefficient**: claps / reading_time (aim for >80)

## Best Practices

- Start with Stage 1 (Quick Assessment) to validate ideas efficiently
- Request deeper analysis only for validated topics to save time
- Use exact character counts for Medium SEO (40-50 title, 140-156 description)
- Balance trending topics with evergreen content for sustained reach
- Leverage personal expertise angles for differentiation
- Test multiple title variants before publishing

## Limitations

- Search data approximations may vary by region
- Medium algorithm changes can affect optimization strategies
- Trend analysis requires web search access for real-time data
- Character limits are strict for optimal SEO performance
