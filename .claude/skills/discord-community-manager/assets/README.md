# Assets Directory

This directory contains ready-to-use assets for the Quack Discord community.

## Contents

### `welcome_embed.json`
Discord embed configuration for welcome messages. Can be used with bots like MEE6 or Carl-bot.

**Usage:**
- Import into your bot's welcome message configuration
- Replace `{{timestamp}}` with actual timestamp when sending
- Customize channel references for your server

### `bot_config/mee6_config.md`
Comprehensive MEE6 bot configuration guide including:
- Auto-moderation rules
- Welcome messages
- Custom commands
- Levels & XP system
- Logging configuration

**Usage:**
- Follow step-by-step to configure MEE6
- Adjust rules based on your community size
- Test all commands before going live

### `server_icon.png` (TODO)
Quack logo optimized for Discord server icon (512x512px, <500KB).

**Requirements:**
- 512x512px minimum
- PNG or JPG format
- Under 500KB
- Transparent background (PNG) or solid color

**Creation:**
Use Quack's existing logo and optimize for Discord specs.

### `banner_template.psd` (TODO)
Photoshop template for Discord server banner (1920x1080px).

**Includes:**

- Brand colors and gradients
- Export settings

**Usage:**
