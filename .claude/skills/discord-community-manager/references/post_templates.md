# Discord Post Templates

Collection of pre-formatted message templates for common Discord community posts.

## Feature Announcement Template

```
🚀 New Feature: [Feature Name]

We just shipped [brief description]!

**What's new:**
✅ Feature/improvement 1
✅ Feature/improvement 2
✅ Feature/improvement 3

**Why this matters:**
- Benefit 1
- Benefit 2
- Benefit 3

Check out the screenshot to see it in action! 🦆

#QuackApp #[FeatureName] #[Category]
```

**Usage:**
```bash
python3 scripts/post_to_discord.py \
  "🚀 New Feature: Clickable Session IDs

We just shipped a major UX improvement for session management!

**What's new:**
✅ Session IDs visible in Sessions panel
✅ Clickable Session IDs in chat messages
✅ Smart UI hides Resume button for active sessions

**Why this matters:**
- Faster session navigation
- Better session visibility
- One-click access to details

Check out the screenshot! 🦆

#QuackApp #SessionManagement #UXImprovement" \
  --image screenshot.png
```

## Template Usage Guidelines

1. **Customize placeholders**: Replace [bracketed text] with actual content
2. **Maintain emoji**: Use consistently across similar post types
3. **Keep hashtags**: Always include #QuackApp + 1-2 relevant tags
4. **Add images**: Screenshots make posts 10x more engaging
5. **Timing**: Post during peak hours (mornings/evenings PST)
6. **Length**: Keep under 2000 characters for readability
