# Community Templates & Message Formats

This document contains ready-to-use templates for common Discord community management scenarios.

## Welcome Messages

### New Member Welcome (Auto-Message)
```
👋 Welcome to the Quack Community, @username!

We're excited to have you here! Quack is a multi-agentic desktop environment built on the Claude Agent SDK.

🚀 Getting Started:
• Check out <#documentation> for installation guides
• Introduce yourself in <#general>
• Share your projects in <#showcase>
• Report bugs in <#troubleshooting>
• Request features in <#feature-requests>

Questions? Ask in <#help> - our community is here to help!

Happy quacking! 🦆
```

### Beta Tester Welcome (DM)
```
🎉 Welcome to the Quack Beta Testing Program!

Thank you for joining! As a beta tester, you'll get:
✨ Early access to new features
🐛 Direct impact on product development
🏆 Recognition in our changelog and community

**What we need from you:**
• Test new features thoroughly
• Report bugs with detailed reproduction steps

• Engage in #beta-feedback discussions

```

## Response Templates

### Bug Report Response (Initial)
```
Thanks for reporting this, @username! 🐛

I've noted this issue. To help us fix it faster, can you provide:

• **OS:** (macOS/Windows/Linux and version)
• **Quack Version:** (Help > About Quack)
• **Steps to Reproduce:**
  1. [Step 1]
  2. [Step 2]
  3. [Step 3]
• **Expected Behavior:** [What should happen]
• **Actual Behavior:** [What actually happens]
• **Error Messages:** (if any - screenshots help!)
• **Console Logs:** (if applicable)

Thanks for helping us improve Quack! 🦆
```

### Bug Report Response (Fixed)
```
Great news, @username! 🎉

This bug has been fixed in version [X.X.X].

**What we changed:**
[Brief technical explanation]

**To get the fix:**
[Update instructions or download link]

Thanks again for reporting this! Your feedback directly improves Quack for everyone. 🦆

If you're still experiencing issues after updating, let us know!
```

### Feature Request Response
```
Great suggestion, @username! 💡

I've added this to our feature request backlog: [Tracking ID or link]

To help us prioritize this, can you share:
• **Your primary use case:** [How would you use this?]
• **Frequency:** [How often would you use this feature?]
• **Current workaround:** [What do you do now instead?]
• **Impact:** [What would this enable you to do?]

We love community-driven development! The features users request most often rise to the top of our roadmap. 🦆

In the meantime, feel free to upvote this request or add additional context!
```

### Support Response (Solution Provided)
```

[Detailed solution/answer with steps]

**Example:**
[Code snippet or screenshot if relevant]

**Additional Resources:**
• [Link to relevant documentation]
• [Link to related tutorial]

[Workaround if available, or "Unfortunately no workaround at the moment"]

```

```

```

**Issue:** [Specific behavior that violated rules]

[Your name]
Quack Moderator

## Usage Notes

**Customization:**
- Replace bracketed placeholders [like this] with actual content
- Adjust tone and emojis to match your community's personality
- Add or remove sections based on your needs

**Best Practices:**
- Always tag relevant channels with <#channel-name> format
- Use Discord's built-in formatting (bold, italic, code blocks)
- Include clear calls-to-action (CTAs)
- Keep messages scannable with bullet points and headers
- Add personality with emojis (but don't overdo it)
- Always end with a friendly sign-off (🦆)

**Template Maintenance:**
- Review and update templates quarterly
- Collect feedback from team on what works
- A/B test different message formats
- Archive outdated templates
