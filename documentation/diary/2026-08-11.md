# Upstream sync scouting and composer latency pick

ahead of our merge-base, 950 files, ~55k lines. Dry-ran cherry-picks on the
highest-value small commits before touching anything, to sort clean picks from
conflict-prone ones:

## Composer activity strip: latency fix

Picked upstream #570. On a top-level thread, the composer strip's work-log
derivation now reuses the already-computed `rawWorkLogEntries` instead of
re-deriving from the full activity history on every live-activity tick
(`resolveComposerStripWorkLogEntries` in `ChatView.logic.ts`). Subagent threads
still derive from their distinct parent source, since they need it either way.

No regressions: same 14 pre-existing browser-test failures before and after
(unrelated Codex model-slug expectations), one additional test now passing,
`ChatView.logic.test.ts` 133/133, typecheck error count unchanged (7,
pre-existing — see below).

See [015-composer-activity-strip.md](../features/015-composer-activity-strip.md).

## Astronaut renamed to Companion in the UI

Provider key and contracts stay `astronaut`; only user-facing copy changed
(settings labels, model-picker title, import-thread message, icon). Also wired
a real health check (`checkAstronautProviderStatus`, `GET /status`) into the
generic provider-status pipeline, so the settings panel now shows Astronaut's
live status the same way it does for every other provider — closes the gap
noted in the original feature doc. Default `enabled` flipped to `true`.

See [017-astronaut-remote-provider.md](../features/017-astronaut-remote-provider.md).

## Claude auth recovery: poll while the card is open

`ChatView` now polls provider status (silent refresh, every 3s) while the
Claude-Agent auth-recovery card is open and the user hasn't re-authenticated
yet, so the card flips to "Login effettuato" on its own instead of requiring a
manual reload. This flow had no feature doc yet — wrote one:
[019-claude-auth-recovery.md](../features/019-claude-auth-recovery.md).

clean at 0 errors, so this branch isn't mergeable until it's fixed. Small,
