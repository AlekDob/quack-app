- [10:30] (Alek) Updated Claude Agent SDK from v0.2.47 to v0.2.50. Migrated deprecated `thinkingMode` string to new `thinking: ThinkingConfig` + `effort` API. The old `thinkingMode` property was silently ignored by SDK, causing Opus 4.6 to always use adaptive thinking (showing THINKING blocks in every response). Key change: stream-claude.js now maps thinking modes to `{ type: 'adaptive' | 'disabled' }` + effort levels ('low'/'medium'/'high'/'max'). Added 'disabled' to ThinkingMode type and 'max' to EffortLevel type.
