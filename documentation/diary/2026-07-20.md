## Agent Mode ↔ IDE toggle perf (085)

Created feature **`085-agent-ide-mode-toggle`**: documents the full shell swap (`App.tsx` AgentModeShell XOR WorkspaceShells), adds `[agent-mode-switch]` instrumentation (`switchPerf.ts`), and a trigger-file sim (`agentModeSwitchSim.ts`).

Live sim (8 open projects, many terminals): Agent→IDE settles ~**558ms** dominated by **terminal reattach cluster (~505ms)** + **chat hydrate (~455ms)**; `editors ready` at ~22ms is a false done signal. IDE→Agent ~**671ms** (filetree + terminal + chat hydrate).

**User console (cold, 102-msg chat):** Agent→IDE ~**4474ms** — `session loaded` loadMs **2661** (`force: true` disk) + 9× terminal attach ~4440ms. Pattern “first slow → then fast → idle slow again” = OS page cache around forced disk reloads. Fix: hydrate keeps rich RAM across remount (`085`); empty new chats covered in `087`. Terminal lazy-mount still deferred.

## Fix: new Agent Mode session ignored Team preset knobs

New chats after **087** seeded an empty RAM body, so hydrate always took the `found` branch and
skipped `applyDefaultPreset`. Result: pill showed Milo (initial state) while model/mode stayed
last-used **Sonnet** / **Auto** instead of Team **Opus** / **Agent**.

Fix: empty hydrate without a persisted model applies `presetIdForEmptyHydrate` via `applyPreset`;
seed `presetId: DEFAULT_PRESET_ID` in `addAIChat`; retry knobs when the agentic CLI becomes
available (`presetKnobsPendingRef`). Vitest: `aiChatPresetApply.test.ts`. Docs `062` + `087`.
