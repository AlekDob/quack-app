- (Alek) Ported the **quack completion sound** from codetta: `apps/web/public/sounds/quack.mp3` + `apps/web/src/lib/quackSound.ts` (cached `HTMLAudioElement`, rewind on replay, autoplay rejection swallowed). Fires once per batch in `taskCompletion.tsx` on chat-turn completion only — not for needs-input or terminal events.
- Key insight: the "completion sound" before this was never ours — it was the OS chime from `Notification({ silent: false })`. So the quack path passes `silent: true` on that same notification, otherwise you hear both. New setting `enableQuackCompletionSound` (default on) gates both the cue and the muting, so turning it off restores the OS chime.
