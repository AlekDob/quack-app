## Composer — stuck-tall textarea after send

Auto-grow only ran in textarea `onChange`. After send / queue / history / session
clear, `setInput("")` emptied the value but left the previous `style.height`
(~8 lines), so the empty composer stayed huge with "Send follow-up".

Fix: `fitComposerInputHeight` on every `text` change inside `ComposerInputHighlight`
(`useLayoutEffect`), which re-renders with ComposerShell input state.

Files: `composerTextareaFit.ts`, `ComposerInputHighlight.tsx`, `AIChatPanel.tsx`, `022`.
