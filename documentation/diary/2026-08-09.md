- [12:05] (Alek) Fixed the question prompt that stayed unanswerable after an app restart. Two defects had to line up: `ProviderService`'s "provider runtime is not active" rejection settled as `retryable` (so the panel stayed open and every click failed identically), and the boot sweep in `startupTurnReconciliation` filtered candidates on `hasPendingUserInput` from the command read model — which builds threads with no activities, making that flag structurally always false. KEY INSIGHT: never read pending-request flags off `engine.getReadModel()`; use the shell snapshot's SQL-computed counts. Full writeup in `documentation/bugs/2026-08-09-restart-stuck-question-prompt.md`.
