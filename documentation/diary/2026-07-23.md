- [00:00] (Alek) Fixed workspace-color persistence: colors were stored in localStorage, which fills up in long-lived installs and silently broke `setJson`, surfacing "Couldn't save the workspace color — local storage may be full." Moved persistence to disk (`colors.json` via Tauri, atomic write); frontend keeps a synchronous RAM cache so render paths (activity bar, agent rail, top bar) are unchanged, with async writes and a one-time migration of the old localStorage map at boot. Updated `documentation/features/002-workspace-colors.md`.
