KEY INSIGHT: l'architettura daemon ha DUE canali per AskUserQuestion (canUseTool callback → top-level message vs SDK stream event → event wrapper) — quando canUseTool non viene chiamato, solo il secondo canale funziona ma il Rust handler lo ignorava.
