# 2026-04-09

- [07:30] (Alek) Investigated "Update Brain button produces no effect" report from Windows user. Found TWO issues:
  1. **Primary**: `onBrainUpdate` called `onSendMessage('/brain')` directly, bypassing `handleSend()` which does slash command expansion. Raw `/brain` sent to SDK → ignored. Fixed by routing through `handleSend('/brain')`. See `bugs/fix-brain-button-bypasses-handleSend.md`.
  2. **Secondary**: `slash_commands.rs` uses `std::env::var("HOME")` 8 times — fails silently on Windows (needs USERPROFILE fallback). Added `get_home_dir()` helper. See `bugs/bug-slash-commands-home-env-windows.md`. Same fix already applied to `rules.rs` and `agency.rs` on 2026-02-17.
