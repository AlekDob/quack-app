- [PM] (Fredric) Completed quantitative payload diff analysis for cache-breaking investigation. Wrote `scripts/cache-payload-diff.mjs` to compare 4 captured `/v1/messages` API payloads byte-by-byte. Key finding: the SDK's `ejY()` serializer strips TodoWrite reminder + `cache_control` from historical messages during re-serialization from disk, breaking the prefix at the most recent user message boundary. Combined with no `cache_control` breakpoints on tools, this forces ~28-33k tokens of re-caching per turn. Root cause is upstream (SDK resume path re-serialization), not Quack-local. Investigation classified as "mixed: local MCP tool ordering fix + upstream SDK blocker". Updated `bug-post-fix-cache-breakage-investigation.md` with full root-cause conclusion.
