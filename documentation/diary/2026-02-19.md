- [17:00] (Alek) Fixed critical IDE file-open bug: clicking a file in EditSummaryBar opened multiple tabs instead of the correct file. Root cause: VS Code-family CLIs (Cursor, VS Code, Windsurf) use bash wrapper scripts with `eval "$CLI" "$@"` that re-parses arguments as a single string, splitting paths with spaces into multiple args. Fix: bypass the wrapper entirely by resolving the Electron binary and cli.js from the .app bundle and calling them directly with `Command::new`. Also fixed `open_multiple_files_in_ide` which had the same `sh -c` + `shell_escape` pattern.
