- [14:00] (Alek) Created `quack-mcp-server.js` — MCP server exposing Quack's agent capabilities to external AI tools. 9 tools: list_projects, list_agents, get_agent, list_sessions, create_session, read_response, send_message, abort_session, answer_question. Architecture: spawns `stream-claude.js` as subprocess per session (same pattern as Rust backend). Registered as built-in MCP server in `stream-claude.js` alongside `ide-tools`. Security: projectPath whitelist, agentId sanitization, event buffer caps, recursion prevention via `QUACK_MCP_CHILD` env var.
