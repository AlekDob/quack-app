## Plan mode + parallel subagents — permission flood + Auto flip

**Problem (reported):** Jack in Plan mode launching 3 Explore subagents still surfaced permission cards; clicking **Allow all** flipped the composer to **Auto** — defeating Plan + formal Build handoff.

**Root causes:**
1. `PLAN_EXPLORE_TOOLS` (2026-07-13) covered Task delegation but not subagent sidechain tools (`WebFetch`, `ToolSearch`, …) or harmless wait Bash (`sleep 1; echo done` blocked by `;` in old `BASH_CHAIN_RE`).
2. **Allow all** always called `setCcPermMode("auto")` even when the composer showed Plan.
3. `getPermModeFor(req)` alone could miss Plan when subagent `cwd`/`session_id` diverged from the chat — card showed **Allow all** instead of **Allow exploration**.

**Fix:**
- `ClaudePermissionOverlay` — `PLAN_READ_TOOLS`, `NotebookRead` in read-only hook set, `parent_tool_use_id` sidechain auto-allow, safer read-only Bash chains (`;`/`&&` when every segment is read-only), Plan-only **Allow exploration** (`planSessionExploreRef`, composer stays Plan).
- `AIChatPanel` — `ownerPermMode={ccPermMode}`; `panelPermMode()` prefers composer over `permModeStore`.
- `claude_perm.rs` — forward `parent_tool_use_id` / `parentToolUseID` on `PermissionRequest`.

**Verify:** `npm run build`; manual — Jack · Plan, launch parallel Explore subagents, confirm no card flood; click **Allow exploration**, composer chip stays Plan (not Auto).

## Context docs click — Agent Mode freeze

**Problem (reported):** Clicking a row in the composer **Context docs** popover (story file, engine feature doc, diary) appeared to crash the app — especially in **Agent Mode** with an active story (`S-001`).

**Root cause:** `openBrainRef` routed story + diary paths through `openFile` on the main editor pane. In Agent Mode `WorkspaceShell` is unmounted, so the tab was created with no visible host — felt like a hang/crash. Feature docs skipped resolution (`documentation/features/` vs `documentation/engine/features/`) and could pass bad paths to the drawer.

**Fix (`workspaceDocOpen.ts`):**
- Story refs → `openStoryDrawer` (lookup by file path in works snapshot).
- Non-feature docs in Agent Mode → `openFileInDrawer` (drawer host in `AgentModeShell`).
- Feature / module docs → resolve on disk first, then `openFeatureDocDrawer` with workspace-relative path.
- Basename search: engine feature + diary candidates; cap `listFiles` at 8k to avoid UI lockups.

**Verify:** Agent Mode + linked story → hover **3 docs** → click story row (story drawer), feature doc (preview drawer), diary (file drawer).

## Workspace color picker — new project import

**Problem (reported):** After importing/opening a new project, right-click → color swatch did nothing — icon stayed neutral.

**Root causes:**
1. Popover sat at `z-index: 210`, below editor drawers/overlays — clicks could miss swatches in WebKit.
2. Colors keyed by ephemeral `wsId`; `openWorkspace` matched roots literally (`/path` vs `/path/`) so re-imports could orphan color entries.
3. Inactive project tint at 13% `color-mix` was nearly invisible on dark badges.

**Fix:** `WorkspaceColorPopover` — `pointerdown` stopPropagation, `type="button"`, deferred close; `workspaceColors.ts` — persist by normalized root + legacy `wsId` fallback; `openWorkspace` — `normalizeWorkspaceRoot`; popover z-index 1200; inactive badge tint 20%.

## Chat perf — typewriter RAF park + works subscription + nav rail

**Problem:** App felt jerky switching chats and typing in the composer — especially during/after assistant streaming.

**Root causes:**
1. `useTypewriterReveal` — infinite `requestAnimationFrame` loop at ~60 fps even when caught up (`lag <= 0`), burning main-thread budget.
2. `ChatNavRail` — `MutationObserver` with `characterData: true` rescanned on every stream glyph.
3. `AIChatPanel` — always-on `subscribeWorks` re-rendered the full 7k-line panel on every `works/` disk write; duplicate of `ComposerWorkBar`'s own subscription.

**Fix:**
- `useTypewriterReveal.ts` — park RAF when caught up; wake on `target` growth; bail-out `setVisible` when slice unchanged.
- `StreamingPlainText.tsx` — `useMemo` on `formatStreamInline(visible)`.
- `ChatNavRail.tsx` — drop `characterData`; use `ResizeObserver` + `childList` for structural/height growth.
- `AIChatPanel.tsx` — lazy `subscribeWorks` only while `@` mention menu is open (`mentionWorksSnap`).

**Works menu:** `ComposerWorkLinkPanel` mounts only when the Work chip menu is open (`ComposerCtxMenu` returns null when closed) — not a typing hot path. `ComposerWorkBar` subscription is isolated to that subtree.

**Work menu layout:** `ComposerWorkQuickActions` icon rows (`+ New work item`, etc.) — `.ai-composer-ctx-menu .menu-item-label` now `inline-flex` (SVG `display: block` had forced icon/text onto separate lines).
