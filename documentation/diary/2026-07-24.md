# 2026-07-24

## Subagent model labels (Cursor-style)

Show the billed model next to Agent/Task chips in the main chat stream and in
the subagent transcript header — same affordance as Cursor (`Haiku 4.5` beside
the subagent title).

### What changed

| Area | Change |
|---|---|
| Live stream | Peek sidechain `assistant.message.model` once per `parent_tool_use_id` → `{ kind: "subagent_model" }` → stamp `ToolCall.model` |
| Chip UI | `.ai-tcall-model` muted label after agent type |
| Transcript | `claude_code_load_subagent` returns `model` via `peek_jsonl_model`; header `.subagent-view-model` |
| Labels | `src/streamModelLabel.ts` — versioned short names (`Haiku 4.5` / `Opus 4.8`); picker stays on `071` aliases |

### Why not tool_input.model?

Local Agent/Task transcripts never carry `model` on tool args. Explore/Plan/etc.
inherit or pick a model at runtime; only the sidechain jsonl stamps
`message.model`. Guessing from `subagent_type` is wrong (Explore is often Haiku,
sometimes Opus/Sonnet).
