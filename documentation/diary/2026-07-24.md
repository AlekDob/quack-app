## Plan ready UX + Agent context column + cross-session fix

Three related Plan / Agent Mode changes (no new feature numbers — updated
`061`, `084`, `088` in place; bug `008`).

### 1. Open Plan on the buy-in card (`088` / `061`)

`PlanBuyInCard` tertiary **Open Plan** → `presentPlanReady` so the user can
re-focus the Agent Mode Plan tab (or IDE FeatureDocDrawer / `plan:` tab) after

| Before | After |

`getPlanBuyIn` cwd fallback made every chat in the project show another
session’s Plan ready card. Ownership is now Quack **`chatId`** (session id
secondary only). Regression: `planBuyInStore.test.ts`.

## Subagent model labels (Cursor-style)

Show the billed model next to Agent/Task chips in the main chat stream and in
the subagent transcript header — same affordance as Cursor (`Haiku 4.5` beside
the subagent title).

### What changed

| Area | Change |
|---|---|
| Live stream | Peek sidechain `assistant.message.model` once per `parent_tool_use_id` → `{ kind: "subagent_model" }` → stamp `ToolCall.model` |
| Chip UI | `.ai-tcall-model` muted label after agent type |
| Transcript | `claude_code_load_subagent` returns `model` via `peek_jsonl_model`; header `.subagent-view-model` |
| Labels | `src/streamModelLabel.ts` — versioned short names (`Haiku 4.5` / `Opus 4.8`); picker stays on `071` aliases |

### Why not tool_input.model?

Local Agent/Task transcripts never carry `model` on tool args. Explore/Plan/etc.
inherit or pick a model at runtime; only the sidechain jsonl stamps
`message.model`. Guessing from `subagent_type` is wrong (Explore is often Haiku,
sometimes Opus/Sonnet).

## Agent chat warm LRU (Cursor-feel switch)

Chat switch in Agent Mode (and IDE hub rail) remounted `AIChatPanel` every hop —
no `tabOpen` equivalent, plus IDE single-slot prune. Audit: `alreadyMounted 0/15`,
hydrate 70–380ms, veil ≥220ms; cross-ws often double-hydrated after veil-down.

### Fix (`092`)

| Piece | Change |
|---|---|
| Warm set | `agentChatWarm.ts` MRU of 5 + per-ws `getAgentSelectedChat` → `tabOpen` |
| Agent Mode | Keep warm hosts mounted; `memo(AgentChatHost)`; `veil: false` on revisit |
| IDE hub | Same LRU in `WorkspaceShell` / `AIChatsRail.focusChat` |
| Veil | Cold first open only |
