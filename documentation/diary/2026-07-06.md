- [08:20] (Alek) **Production fixes — model picker clip + Quit dead.** (1) `ModelPickerPopover` portaled with `position: fixed` (same pattern as `EffortPopover`) so the composer model menu isn't clipped by `.ai-panel { overflow: hidden }` in Agent Mode. (2) macOS **Quit / ⌘Q** silent after Dock opens — Tauri 2 drops custom native-menu callbacks when another webview took focus; `refreshNativeMenuBinding()` on main `onFocusChanged` + after `openDock()`. (3) `appQuit.ts` tears down Dock + popouts before main closes so Quit actually exits the app. Files: `ModelPickerPopover.tsx`, `nativeMenu.ts`, `appQuit.ts`, `actions.ts`, `App.tsx`, `App.css`.
- [08:32] (Alek) **Claude Code missing from model lists.** Regression from `1d23dc9f` deferred cloud catalog: composer picker read empty `allCloudCatalog`; opening the picker first merged only OpenCode into `cloudCatalog`, so Model Browser skipped the full fetch and showed "No models match" despite CLI detected. Fix: picker uses `allModels`; `cloudCatalogComplete` flag; live CLI merges no longer pollute partial catalog. Files: `modelDiscoveryStore.ts`, `AIChatPanel.tsx`, `031-model-discovery-cache.md`.
- [08:46] (Alek) **⌘Q blocked in production.** Quit teardown closes Dock/popouts via `WebviewWindow.close()` → `destroy` under the hood; release builds enforce capabilities and `core:window:allow-destroy` was missing (dev is permissive). Added permission + `.catch()` on auxiliary closes. Files: `capabilities/default.json`, `appQuit.ts`, `dock.ts`.
- [08:55] (Alek) **Terminal backspace → space in production.** Root cause: GUI launch (`.dmg`/Finder) inherits no `TERM`, unlike `tauri dev` from a shell — zsh line editing echoed spaces on delete. Fix: `apply_pty_env` sets `TERM=xterm-256color` + `COLORTERM` on spawn; `TerminalCore` bypasses WKWebView textarea routing for Backspace/Delete (`\x7f` / `\x1b[3~` straight to PTY). Files: `pty.rs`, `TerminalCore.tsx`, `App.tsx`.
- [08:58] (Alek) **Terminal PATH in production.** Same GUI-launch gap: minimal PATH (no Homebrew/nvm) so `git`/`node`/`brew` missing; `dir` is Windows-only (`ls` on macOS). Fix: `login_shell_path()` caches PATH from `zsh -ilc`; PTY spawns as login shell (`-l` / `--login`); Windows PATH merge moved into `apply_pty_env`. Files: `pty.rs`.
- [11:35] (Alek) **Fix production freeze after composer queue.** Queuing a follow-up during an active turn could peg WebKit at ~100% CPU and tens of GB RAM until the app hung (observed on `/Applications/Quack.app` with Virgilio workspace). Root cause: `drainQueue` used a `while` loop; when `sendUserText` re-queued defensively because stale React `streaming === ""` (between tool rounds) or `runningTools` in closure, `shift`+`pushQueue` left queue length unchanged and the loop never exited — synchronous `setQueuedMessages` / `flushSessionState` storm. Fix: drain **one** message per `finally`; defensive guard in `sendUserText` uses `liveTurnRef` (cleared synchronously before `setTimeout(drainQueue)`), not `streaming` state; `stop()` clears `liveTurnRef`. Docs: expanded `039-composer-queue.md` (production-freeze table, drain diagram, `liveTurnRef` contract), `022` cross-ref. Files: `AIChatPanel.tsx`.
- [16:50] (Alek) **Mermaid `.mmd` diagram preview.** Opening `.mmd` showed raw text only (no renderer). Added lazy-loaded `mermaid` + `MermaidPreview` with Edit/Split/Preview toolbar (same as markdown); `.mmd` tabs default to **Preview** so Monaco doesn't mount on open. Theme-aware (`dark`/`default`), debounced re-render, syntax errors surfaced inline. Docs: new `042-mermaid-preview.md`, updates to `027`, `017`, `013`, `CLAUDE.md`. Files: `MermaidPreview.tsx`, `editorMermaidView.ts`, `EditorPane.tsx`, `EditorTabToolbar.tsx`, `langDetect.ts`, `fileIcons.ts`, `App.css`, `package.json`.
