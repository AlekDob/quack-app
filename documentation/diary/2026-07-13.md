## Mermaid preview — zoom, sizing, and fit-to-viewport

**Problem (reported on Virgilio `.mmd` sequence diagrams):**
- Diagram rendered tiny in the top-left at “100%” — illegible.
- Trackpad pinch zoom felt sluggish / hard to control.
- After zooming even slightly (~103%), the diagram appeared to vanish (blank viewport).

**Root causes:**
1. Mermaid `render()` emits SVG with `width="100%"`. Inside `.mermaid-preview-stage` (shrink-to-fit `inline-block`), the SVG collapsed to a few pixels.
2. Old `syncStageBox()` set the stage layout box to `base × scale` **and** applied `transform: scale(scale)` on the same node — double-scaling. Scroll extents no longer matched visual size; `scrollForZoom` panned content off-screen.
3. Pinch factor `exp(-deltaY * 0.002)` was too gentle for macOS pixel deltas.

**Fix:**
- `mermaidZoom.ts`: `normalizeMermaidSvg`, `readMermaidSvgSize`, `syncMermaidScrollSizer`, `fitMermaidScale`; pinch tuned to `0.006`.
- `MermaidPreview.tsx`: spacer `.mermaid-preview-sizer` for scroll box; stage transform-only; `afterSvgPaint()` normalizes + fits on first render.
- `App.css`: sizer + absolute stage layout.
- Feature doc `042-mermaid-preview.md` updated with DOM layout diagram and gotchas.
