# 2026-07-31

## Cursor CLI — false "Install cursor-agent" after rebuild (bug 009)

Model Browser showed Cursor CLI as missing after a rebuild / GUI launch even
though `cursor-agent` was installed and logged in (`~/.local/bin`).

**Root cause:** `resolve_cursor_bin` cached a bare `cursor-agent` name from a
login-shell probe, then `Command::new` failed because Dock / IDE launches often
omit `~/.local/bin` from process PATH — check/spawn disagreed with the shell
probe; home-path fallback never ran. Frontend soft discovery + Model Browser
early-return on stale `cursorCliAvailable: false` amplified it.

**Fix:**
- Rust: PATH → `~/.local/bin` → `command -v` absolute → `cursor agent`; never
  cache a bare name from shell (`shell_which`)
- TS: force refresh invalidates Cursor cache + awaits probe;
  `ensureLiveCliCatalogs` for browser open

Docs: bug `009`, features `026` + `031`.

Files: `cursor_code.rs`, `modelDiscoveryStore.ts`, `AIChatPanel.tsx`.

## Agent Mode — right column collapsed by default

Cursor-style minimal right rail: the Agent context column now starts **collapsed**
to a 40px icon strip (add-view / Changes / Files / Plan / Terminal) and only expands
on demand — the expanded panel is unchanged. Collapse is global + persisted
(`lcp.agent.contextCollapsed`, default `true`); every `focus*` helper expands first
so StatusBar / Ctrl+J / Ctrl+B / Plan buy-in keep working, and `toggleAgentFiles` /
`toggleAgentTerminal` collapse back when that view is already open. The drag
splitter is hidden while collapsed.

Files: `agentContextNav.ts` (+ `agentContextCollapse.test.ts`),
`AgentContextColumn.tsx`, `AgentModeShell.tsx`, `App.css`, `084`.

## Agent Mode — Docs tab from the chat stream

New **Docs** tab (+ rail icon) in the right column: lists every `.md`/`.mmd` the
agent touched in the current chat, appearing live mid-stream and hiding when the
chat has none. Row click reuses `openWorkspaceDocPath`, so feature docs land in
the FeatureDocDrawer and other docs in the md drawer — no new opening path.
Collection reuses `pathOf` from `chatToolRender` and publishes from the same
`AIChatPanel` effect as `publishChatDiff`; reads count as "treated", a write
anywhere in the chat flips the `edited` badge.

Also fixed while here: the Plan/Docs/closed-terminal **fallback** effects called
`setContextPanel`, which force-expands the collapsed rail — they now call
`setAgentContextPanel` (selection only), so a background chat switch can't pop
the panel open.

Files: `chatDocsStore.ts` (+ test), `AgentDocsPanel.tsx`, `AgentContextColumn.tsx`,
`agentContextNav.ts`, `AIChatPanel.tsx`, `App.css`, `084`.
