- [10:00] (Alek) Aggiornata skill-creator da v1.0.0 a v2.0.0 (synced con anthropics/skills upstream). - [10:30] (Alek) Implementato sistema di versioning + update per il Quack Store. Tre problemi risolti: (1) nessun tracking delle versioni installate, (2) skill installate solo con SKILL.md ignorando scripts/references/assets, (3) nessun meccanismo di update nell'UI. Soluzione: registry JSON centralizzato (`~/.claude/plugins/quack-installed.json`), download completo directory skill via GitHub Contents API con fallback, badge "Update vX.Y.Z" arancione nella card e bottone nel modal. File creati/modificati: `marketplaceRegistryService.ts` (nuovo), `useMarketplace.ts`, `MarketplaceCard.tsx`, `MarketplaceInstallModal.tsx`, `MarketplaceDrawer.tsx`. KEY INSIGHT: retrocompatibilità gestita con versione "unknown" per installazioni pre-registry — nessun falso positivo di update.
