- [Fix] (Alek) Context & Usage drawer no longer flashes the amber "Plan limits: request failed: http status: 429" box at session start. The claude.ai `claude_usage_limits` OAuth endpoint rate-limits aggressively (429) and the 30s poll fires immediately on chat open; the first transient failure was surfaced as an error even with THIS CHAT at 0. Now the poll catch treats 429/rate-limit/network blips as non-errors, keeps the last-known cached limits silently, and only shows an error when there is genuinely no data AND the failure isn't transient. `AIChatPanel.tsx` poll catch (~L3481). See feature 019-usage-monitor.
