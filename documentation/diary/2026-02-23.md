Three-pronged fix: (1) Node resolution now collects ALL candidates and picks highest major version (nvm v22 > Homebrew v18), (2) MIN_NODE_VERSION bumped 18→20, (3) CJS polyfill loaded via --require for Node 20-21 (runs before ESM evaluation, solving hoisting).
