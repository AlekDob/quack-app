- [10:00] (Alek) feat(debug): Auto-inject `systematic-debugging` skill in Debug mode. Instead of a brief 5-point summary, the full skill content is now read from bundled `src-tauri/node-sdk/skills/systematic-debugging.md` and injected into the system prompt when `debugMode === true`. Users no longer need to manually install or invoke the skill. Updated both `stream-daemon.js` and `stream-claude.js` with `loadBundledSkill()` helper + fallback to summary if file not found. Updated `pattern-permission-modes.md` documentation.

- [16:30] (Alek) fix(remote): Mobile dashboard agent status always "IDLE" even when agent is busy. **ROOT CAUSE**: `UnifiedAgent` struct has no `status` field — agent busy/idle is tracked only in React in-memory state, never persisted to `quack-agents.json`. The REST API read from disk → always "idle". **FIX**: Created `AgentStatusMap` (`Arc<RwLock<HashMap<String, String>>>`) in `lib.rs`, updated by `handle_status_update` (same hook that feeds React + WebSocket), read by `/api/agents` in `handle_list_agents`. Also added `Cache-Control: no-store` to JS/CSS responses, `/api/ordering` + `/api/groups` endpoints for sidebar ordering, and session dot color logic mirroring Mac behavior.

- [18:00] (Alek) fix(remote): Agent status map was NEVER populated for internal agents — only `POST /terminal/status` wrote to it, but nobody calls that for Quack's own agents. **ROOT CAUSE**: Internal agents stream events through `daemon_stdout_reader` (daemon mode) and `send_message_via_sdk_streaming_legacy` (legacy mode), neither of which updated the `AgentStatusMap`. **FIX**: Made `AgentStatusMap` a global static (`AGENT_STATUS` in `lib.rs`), updated from all 3 sources: (1) `/terminal/status` hook, (2) daemon event handler (assistant→busy, result→idle), (3) legacy streaming handler. Also mark agents "busy" IMMEDIATELY when `handle_execute`, `handle_send_message`, or `send_message_via_sdk_streaming` are called — eliminates the gap between "message sent" and "first assistant event". The REST API now sees live busy/idle status for all agents at every phase.
