- [09:05] (Alek) **New-chat intermittent slowness — unmemoized host fan-out.** Investigated the create-chat path: `addNewAIChat` → `pulseChatSwitch({veil:false})` (no flush), `addAIChat` (persistWs is debounced, not sync), `focusAIChat` (light). So the cost is the render cascade: adding a chat mutates `loaded` → `WorkspaceShell` re-renders and re-creates EVERY mounted `AIChatHost`, and since `AIChatHost` wasn't memoized each re-rendered its full 7382-line `AIChatPanel`. So new-chat cost scaled O(#mounted panels) — intermittent because it depends on how many chats you have open/sticky. Fix: `memo(AIChatHost)` (props are primitives + stable container/root refs) so only the new host + the one losing focus re-render — mirrors `memo(WorkspaceShell)`. Also added dev `[new-chat-perf]` timing (`markNewChat` in addNewAIChat + `logNewChatPhase` panel mounted/painted in AIChatPanel) to confirm click→mount cost. KEY INSIGHT: same root cause as the project-switch fanout — big unmemoized components re-rendering N-wide on an unrelated `loaded` mutation; memoize the per-item host so one item's change doesn't re-render the rest.
