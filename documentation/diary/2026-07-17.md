- [00:00] (Alek) Workspace color fix + custom picker. Prod couldn't color new projects while dev could + old projects kept their color → not a logic bug (id/color-key are deterministic from the normalized root, symmetric set/read), but a full prod `localStorage`: existing color keys survive, new `setItem` fails. Root cause was masked because `setJson` swallows quota errors silently. Fix: `setWorkspaceColor` now surfaces a toast when the write fails. KEY INSIGHT: "old keeps / new fails, dev ok / prod no" is the signature of a full per-origin localStorage, not a code path difference.
- [00:00] (Alek) Added custom workspace color via native color picker in `WorkspaceColorPopover`. Model change: a stored value is now either a preset id ("blue") OR a raw hex ("#7c3aed"); `getWorkspaceColor` returns a synthetic `{id: hex, label: "Custom", hex}` for hex values (`isHexColor` guard). New last swatch = rainbow conic-gradient ring (unset) / picked hex (set) with a transparent `<input type=color>` filling it so a click opens the OS picker. All existing consumers use `.hex`, so title-bar wash / dock / rail work unchanged.
- [08:50] (Alek) **Cold project-switch loader** (`079`, sibling of `075`). Some projects still feel laggy on switch-in; rather than chase every ms, mask the cold mount with a branded full-window wash in the project's color. `workspaceSwitchLoader.ts` (begin on cold switch = `prevId && !isWorkspaceWarm(id)`, end on editors-ready; SHOW_DELAY 90 / MIN_VISIBLE 320 / CAP 2500) + `WorkspaceSwitchVeil.tsx` (radial gradient in `--ws-load-color` over `--bg`, initials badge + name, pulse). Warm (last-3) projects skip it → still instant. Also added `switchPerf.ts` — dev-only `[switch-perf]` timing (`markSwitchStart` + `logSwitchPhase` on FileTree root list_dir + editors-ready) because the existing `[chat-switch]` logs only measure `setActiveWorkspace` (fast) and miss the real mount cascade. KEY INSIGHT: the switch-slowness criterion is warm-vs-cold, not project size — instrument the uninstrumented phases, and where you can't cheaply cut the cost, mask it (perceived perf) with the per-project color the design system already reserves for identity.
