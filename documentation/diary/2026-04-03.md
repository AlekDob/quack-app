- [11:00] (Alek) fix: Ask mode non chiedeva permesso — due root cause. (1) canUseTool in stream-daemon.js auto-approvava tutti i tool. Fix: aggiunto sistema tool_permission_request (Rust→daemon→frontend). (2) **La vera root cause**: `allowedTools` nel daemon includeva Write/Edit/Bash che il SDK auto-approva al punto 4 della catena di valutazione, PRIMA che `canUseTool` venga mai chiamato. Documentazione SDK conferma: Hooks → Deny rules → Permission mode → **Allow rules** → canUseTool. Fix: in Ask mode, `resolvedAllowedTools` usa solo tool read-only (Read, Glob, Grep, AskUserQuestion, ExitPlanMode, TodoWrite) così Write/Edit/Bash cadono nel canUseTool per approvazione utente.
