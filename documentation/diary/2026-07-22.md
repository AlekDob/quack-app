- [11:30] (Alek) **Bug fix: queued follow-ups vanishing mid-transcript.** Reported: queueing several messages in a row while a turn was running (`considera che uso ai coding` → `bruttolan lo fanno loro direttamente manualmente`) made the middle ones disappear from the chat UI, even though the agent's reply clearly reflected their content. Root cause: `sendUserText` (`AIChatPanel.tsx`) commits the new user bubble with `setMessages([...baseMessages, displayUserMsg])`, where `baseMessages` is a snapshot captured **before** several `await`s (Brain lookup, workspace-rules load, system-prompt assembly). If another drained queue item committed its message during that window, this later replace silently overwrote it — the model still saw the correct `conversation` array (built independently of React state), so the reply was right but the UI lost a bubble. KEY INSIGHT: fixed by using a functional updater — `setMessages((prev) => [...prev, displayUserMsg])` — so every commit is additive onto the latest state instead of replacing with a stale snapshot. Feature `039-composer-queue.md` updated with a new gotcha section (do not revert to the plain-replace form).
