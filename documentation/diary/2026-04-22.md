- [14:00] (Fredric) Added plugin-skill discovery to the Skills panel — `~/.claude/plugins/installed_plugins.json` is now walked alongside the global and project trees, and `superpowers:*` (and any other plugin-bundled) skills now show up in a new "Plugin Skills" section of the sidebar and in the `@` autocomplete. Names use the SDK-native `<plugin>:<skill>` form so `@skill:superpowers:brainstorming` round-trips unchanged into the agent. Frontmatter `description:` now beats the first `#` heading everywhere, which improves the blurb text on the bundled skills too. Breadcrumb + gotcha at `documentation/gotchas/gotcha-claude-plugin-skills-discovery.md`.
