Risultato: canvas height 0 → `getBoundingClientRect().height === 0` → `fit-to-content` bailava (guard sul rect zero) → nulla renderizzato. Gotcha generale riutilizzabile: **flex:1 in un figlio richiede che il parent sia `display:flex`, silenzioso altrimenti** — errore comune quando intercali un wrap `position:relative` per ancorare toolbar/overlay senza rendere flex il wrap stesso.
