# WS01 — Claude Agent SDK 0.2.138 → 0.3.150 upgrade

## Goal

Allineare il pin `@anthropic-ai/claude-agent-sdk` da `^0.2.138` (gennaio 2026) all'ultima minor `^0.3.150` (maggio 2026). Sbloccare le feature aggiunte tra 0.2.139 e 0.3.150 (`skills` option, `forwardSubagentText`, `managedSettings`, `updatedToolOutput` universale, native binary export per Bun, `resolveSettings()` alpha) e adeguare Quack ai breaking changes della serie 0.3.x — in particolare il rename wire-level di `TodoWrite` in Task tools e la nuova default non-blocking sui server MCP.

## Scope

- **Migrazione rendering Task tools** nei 4 file FE che oggi matchano solo `'todowrite'`:
  - `src/components/ToolCallCard.tsx:16`
  - `src/components/ToolCallMinimal.tsx:18`
  - `src/components/ChatView.tsx:768`
  - `src/components/StreamMessage.tsx:505`
  Dopo 0.3.142 il wire name passa a `TaskCreate` / `TaskUpdate` / `TaskGet` / `TaskList` e i tool consumer **devono accumulare per task ID** invece di sostituire uno snapshot. Va rivisto anche `TodoWriteWidget` per supportare entrambi i formati durante la transizione.
- **Retest del workaround AskUserQuestion** (`fix-askuserquestion-sdk-0.2.138-pretool-posttool-hook.md`) su 0.3.150 in branch isolato. Verificare se il PreToolUse + `additionalContext` continua a funzionare o se SDK ha cambiato la pipeline.
- **MCP non-blocking default (0.3.142)**: validare che `gotcha-mcp-server-timeout-slow-startup.md` venga risolto (positivo) e che server lenti riportati come `status: "pending"` non rompano nessun listener init Quack. Decidere se serve marcare server critici con `alwaysLoad: true`.
- **Lockfile pulito**: `@anthropic-ai/sdk` e `@modelcontextprotocol/sdk` ora sono peerDependencies (0.3.143) — npm li auto-installa, ma è bene rigenerare lockfile e verificare che il bundle Tauri ricompili senza warning.
- **Aggiornamento skill `claude-agent-sdk`** in `.agents/skills/claude-agent-sdk/SKILL.md` per riflettere la 0.3.150 (oggi è ferma a 0.2.85).
- **Bump pin** `src-tauri/node-sdk/package.json`: `^0.2.138` → `^0.3.150`.

Fuori scope: migrazione completa a Task tools nativi (Quack continua a esporre `TodoWrite` ai modelli per retrocompatibilità — il commento in `stream-daemon.js:418` è già forward-compat).

### Features nuove rilevanti per Quack

- **0.2.118** `Options.managedSettings` — embedder può passare policy-tier inline. **Quack è l'embedder per definizione.** Da valutare per `~/.quack/settings`.
- **0.2.120** `skills` option (`string[] | 'all'`) — Quack già usa `skills: 'all'` (`stream-daemon.js:450`).
- **0.2.121** `updatedToolOutput` su PostToolUse per qualunque tool (non solo MCP). Potrebbe semplificare il workaround AskUserQuestion.
- **0.2.119** `forwardSubagentText` — stream subagent text deltas. Potenziale upgrade UX per droid reports.
- **0.2.72** `agentProgressSummaries` — summary periodici per subagent in background. Si lega a `pattern-agent-result-card.md`.
- **0.2.89** `startup()` pre-warm — first query 20x più veloce. Da valutare per perceived latency.
- **0.2.86** `getContextUsage()` — breakdown contesto per categoria. Si lega allo StaminaBar.
